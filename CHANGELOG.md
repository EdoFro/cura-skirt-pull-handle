# Changelog

## 0.5.0

- Adds a non-planar pull handle to the top layer of each independent skirt.
- Supports curved skirts and multiple objects printed sequentially.
- Optionally adds an early handle to the first layer.
- Optionally adds a connector between the skirt and the model.
- Restores the previous fan state after printing a handle.
- Includes Cura integration and a command-line mode.
